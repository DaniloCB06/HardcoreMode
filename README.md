# HardcoreMode (Hytale Mod)

## Overview
HardcoreMode is a server-side mod that increases mob health and damage.
It provides a GUI to configure multipliers per mob category, a Blood Moon
event with scheduling and force options, and player death settings.

## Dependencies


Optional:
- TinyMessage API for red chat messages when Blood
  Moon starts/ends. If not present, messages fall back to plain text.


## Command
- `/hardgui` - Opens the Hardcore Mode settings GUI.
  - Permission: admins/ops only.
  - Hidden from `/help` for players without permission.

## GUI Settings
Enemy Settings (left panel):
- Global Hardcore Mode: toggles all categories at once.
- Global Health/Damage: base multipliers for all categories.
- Peaceful/Neutral/Hostile: per-category enable + health/damage multipliers.

<img width="1293" height="711" alt="image" src="https://github.com/user-attachments/assets/b254839c-16c0-46c8-bbed-896842fa3e26" />

Blood Moon (right panel):
- Enable/disable automatic Blood Moon.
- Every X Days: interval in days.
- Start Hour: hour of day (0-23).
- Duration: 1h / 3h / 6h / 9h / 12h.
- Hostile Health/Damage: multipliers applied during Blood Moon.
- Force Blood Moon: triggers it immediately for the selected duration.

Player Settings (right panel):
- Death Settings: enable/disable death penalties.
- Item Durability Loss: percentage of durability lost on death.
- Inventory Drop Loss: percentage of items dropped on death.

Notes:
- GUI sliders use 1x to 5x. You can set any value in the JSON config.
- When Blood Moon is active, its hostile multipliers override the left-side
  hostile settings, even if the hostile category is disabled.

## Configuration
The config file is generated by the server config system (HardcoreMode.json).
You can edit it to use values outside the GUI slider range.
